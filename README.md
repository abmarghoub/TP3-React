## 1. Objectif du TP
- Le rendu conditionnel avec opérateurs ternaires et logiques.
- L’itération avec `map()`.
- La mise en place de la navigation avec React Router.
- L’intégration d’images, de médias et de styles CSS.

---

## 2. Architecture du TP

### 2.1 Stack technologique
| Technologie        | Version / Description                              |
|-------------------|----------------------------------------------------|
| React             | Bibliothèque JavaScript pour les interfaces UI    |
| React Router DOM  | Gestion de la navigation interne (SPA)           |
| JavaScript ES6+   | Langage de programmation                          |
| HTML / JSX        | Structure et rendu des composants                 |
| CSS               | Styles et mise en forme                             |
| Node.js / npm     | Gestionnaire de paquets et serveur de développement |
